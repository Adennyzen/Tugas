# ARUNA — Tropical Residence

[Download the complete Blender project ZIP](https://github.com/Adennyzen/Tugas/raw/refs/heads/aruna-download/ARUNA_Tropical_Residence_Package.zip)

The package includes the native `.blend` project, eight 1600 × 1200 PNG renders, embedded procedural materials, and verification documentation. No script execution is required to open the project.

The native project was saved in Blender 4.3.2 and reopened and rendered using Blender 5.2.2 LTS. Day lighting is at frame 1; night lighting is at frame 120.

This download is stored on the `aruna-download` branch.

Check the archive against `ARUNA_SHA256SUMS.txt` if needed.
