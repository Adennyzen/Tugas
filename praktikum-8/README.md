## Cara mencoba di laptop

1. Unduh dan ekstrak `p8-integrasi.zip`.
2. Buka `p8-integrasi/README.md` hasil ekstraksi.
3. Ikuti panduan instalasi Python, Docker/RabbitMQ, dependensi, dan urutan menjalankan layanan untuk Windows/macOS/Linux.

ZIP juga memuat laporan analisis, PDF modul, tangkapan layar, serta bukti **44 pemeriksaan integrasi dan 14 pemeriksaan browser yang lulus** di Linux. Windows/macOS belum diuji langsung.

Checksum tersedia di [p8-integrasi.zip.sha256](p8-integrasi.zip.sha256). Unduhan tidak menyertakan virtual environment atau image Docker; koneksi internet diperlukan untuk instalasi awal.
